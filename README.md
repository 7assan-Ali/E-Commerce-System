# E-Commerce System

A Python-based Object-Oriented E-Commerce System built from the project UML design.

## Structure

- `src/models/` - Core domain classes
- `src/services/` - Business logic services
- `tests/` - Automated tests
- `src/main.py` - Application entry point

## Planned GUI

A separate GUI layer will be added after the core models and business logic are completed.
